# Arendator

Монорепозиторий первой версии сервиса аренды инструментов и оборудования.

Требования к продукту определены в [SPEC.md](SPEC.md). Отложенные функции ведутся в [TODO.md](TODO.md).

## Текущий статус

Подготовлена начальная структура репозитория. Backend и frontend ещё не созданы, зависимости не установлены, приложение не запускается.

## Структура

```text
backend/             будущий Django backend
frontend/            будущий React SPA
docs/decisions/      архитектурные решения
docs/diagrams/       диаграммы
docs/sessions/       итоги сессий разработки
.agents/skills/      локальные навыки Codex для репозитория
```
